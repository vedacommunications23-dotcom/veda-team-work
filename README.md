## Enable GitHub Pages

1. Repo **Settings** → **Pages**
2. Source: **Deploy from a branch**
3. Branch: `main` / folder: `/ (root)` → Save
4. Site URL will be like: `https://YOUR-USERNAME.github.io/REPO-NAME/`

## Connect GoDaddy domain later

In GoDaddy DNS for `vedacibilservices.com`, add the records GitHub Pages shows (A records + CNAME for `www`).
